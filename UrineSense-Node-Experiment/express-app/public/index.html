UrineSense

Urine Test Strip Reader Using Colorimetry

About the Project

UrineSense demonstrates a web interface for a colorimetry-based urine test strip reader.

View Sample Results View JSON Response

How Colorimetry Works

  1. A test strip contains reagent pads.
  2. The pads change color after exposure to a sample.
  3. The colors are compared with a reference chart.
  4. The comparison can produce estimated readings.

This is an educational demonstration, not a clinically validated diagnostic system.
